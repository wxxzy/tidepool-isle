# 《潮汐小岛》实战教程索引

这套教程把「用 AI 生成资产 + Godot 做一个能跑的小游戏」拆成 10 步。
每一步都是一个能独立验收的落地点，**做完一步就能看到东西**，不会出现"写了三千行还是黑屏"的情况。

代码全部在这个仓库里，教程只讲「为什么这么写」和「我在哪里翻过车」。

---

## 怎么用

- **想快速跑起来**：直接看根目录 `README.md` 的「运行」，跳过教程。
- **想学做法**：按顺序读，每篇 15–30 分钟，跟着敲。
- **只想抄某一环**：第 05–09 篇是 AI 3D 资产流水线，可以独立食用。

## 这条路的三个核心方法论

写到最后我发现，真正值钱的不是代码，是下面三条：

1. **编译通过 ≠ 做好。** 一定要用真实渲染截图验收，headless 跑通只证明"没崩"。
2. **AI 出的资产不能用默认参数直接吃。** 面数、贴图、坐标系、骨骼，四项至少要动三项。
3. **每个坑都要变成一条断言。** 修完 bug 不写测试，下次换个模型还会踩。

## 环境

- Godot **4.7.1**（GL Compatibility 渲染器，为 Web 导出）
- Python **3.11**（`requests` / `Pillow`）
- Blender **5.2**（绑骨用，headless 跑脚本）
- 腾讯混元生3D API Key（第 05 篇用，可选）
