# 09 · 动画状态机与钓线绑定点

> 目标：让主角在待机/走路/持竿之间自然切换，并且钓线永远从竿尖出发。
> 预计 30 分钟 · 前置：第 08 篇

---

## 状态机只有三行

不需要 `AnimationTree`，也不需要状态图。三个状态，一个 `if`：

```gdscript
func _animate_glb(dt: float, speed: float) -> void:
    _update_rod_tip()
    if _anim == null:
        _animate_whole_body(dt, speed)   # 没有骨骼时的降级方案
        return

    if frozen:                    # 持竿中
        _play("hold")
    elif speed > 0.15:            # 在动
        _play("walk")
        _set_anim_speed(speed / WALK_SPEED)
    else:
        _play("idle")
```

### `_play()` 要防抖

不加这个判断，每帧都会 `play()` 一次，动画永远停在第一帧：

```gdscript
func _play(name: String) -> void:
    if _anim == null or _anim_name == name:
        return                      # ← 同名不重播
    if not _anim.has_animation(name):
        return
    _anim_name = name
    _anim.play(name, 0.18)          # 0.18 秒混合，切换不会"抽一下"
```

### 步行速度要跟动画速度挂钩

固定 1.0 倍速下，角色踩着沙地（0.85 速）走路会显得"原地快蹬"，像个打滑的玩偶：

```gdscript
func _set_anim_speed(mult: float) -> void:
    if _anim == null or _anim_name != "walk":
        return
    _anim.speed_scale = clampf(mult, 0.55, 1.9)
```

上下限要卡：太快像抽搐，太慢像慢放。

## 钓线起点：这是最容易错的一处

### 错误做法 1：写死一个偏移

```gdscript
rod_tip.position = Vector3(0.1, 2.2, 0)   # 建模时量出来的
```

站定时看着没问题，**一抬竿就露馅**：竿尖上移了，钓线还从原来位置出发。

### 错误做法 2：`BoneAttachment3D`

看起来是正解——Godot 有专门的"挂在骨骼上"节点：

```gdscript
var att := BoneAttachment3D.new()
att.bone_name = "hand.R"
att.position = rest.affine_inverse() * tip_in_skeleton_space
skel.add_child(att)
```

我这么写完，跑 `tests/player_size.gd` 一量：

```
rod_tip world=(..., 5.753, ...)     feet_y=4.873
→ 竿尖只高出脚底 0.88m
```

实际竿尖该在 2.20m。**偏移被多算/少算了一个层级**（glTF 导入的骨架有嵌套变换，
`BoneAttachment3D` 的局部空间和你以为的不是同一个）。

### 正确做法：每帧自己算

```gdscript
var _skel: Skeleton3D = null
var _hand_idx := -1
var _tip_offset := Vector3.ZERO   # 竿尖在 hand.R 骨骼空间的偏移

## 建立阶段：把"世界坐标的竿尖"换算成"骨骼空间的偏移"
func _setup_rod_tip(body: Node3D, local_tip: Vector3) -> void:
    _hand_idx = _skel.find_bone("hand.R")
    var to_skel: Transform3D = _skel.global_transform.affine_inverse() * body.global_transform
    var p_skel: Vector3 = to_skel * local_tip               # body 本地 → 骨架空间
    var rest: Transform3D = _skel.get_bone_global_rest(_hand_idx)
    _tip_offset = rest.affine_inverse() * p_skel            # 骨架空间 → 骨骼空间

## 每帧：竿尖 = 骨架世界变换 × (手骨当前位姿 × 偏移)
func _update_rod_tip() -> void:
    if _skel == null or _hand_idx < 0 or rod_tip == null:
        return
    var pose: Transform3D = _skel.get_bone_global_pose(_hand_idx)
    rod_tip.global_position = _skel.global_transform * (pose * _tip_offset)
```

再量：

```
rod_tip world=(..., 7.073, ...)     feet_y=4.873
→ 2.20m  ✅ 正好在竿顶
```

**好处不只是准，还能被断言。** 集成测试里直接写：

```gdscript
_check(tip.global_position.y > p.global_position.y + 1.2,
    "竿尖在手骨上方（相对脚底 %.2fm）" % (tip.global_position.y - p.global_position.y))
```

## `local_tip` 从哪来

模型里**最高的那个顶点就是竿尖**（因为竿向后上方伸）。所以不用手量：

```gdscript
static func topmost_local(n: Node3D) -> Vector3:
    var best := Vector3.ZERO
    var best_y := -INF
    for ch in n.find_children("*", "MeshInstance3D", true, false):
        var mi := ch as MeshInstance3D
        for s in mi.mesh.get_surface_count():
            var verts: PackedVector3Array = mi.mesh.surface_get_arrays(s)[Mesh.ARRAY_VERTEX]
            for v in verts:
                var p: Vector3 = mi.transform * v
                if p.y > best_y:
                    best_y = p.y
                    best = p
    return best
```

13k 顶点遍历一次，加载时几百毫秒的事，比手量靠谱。

> 注意返回的是**本地坐标**。如果返回父空间坐标再去挂骨骼，会重复乘一次缩放——
> 我第一版就踩了，竿尖飞到 6.27m 高。

## 整体运动降级方案（没有骨骼时）

不是每个模型都能绑骨。没有 `_anim` 时用整体运动顶上：

```gdscript
func _animate_whole_body(dt: float, speed: float) -> void:
    var moving := speed > 0.15
    if moving:
        _walk_phase += dt * (5.2 + speed * 1.15)
    var bob := (absf(sin(_walk_phase)) - 0.5) * 0.075 if moving else 0.0
    var roll := sin(_walk_phase) * 0.055 if moving else 0.0
    _glb_root.position.y = lerpf(_glb_root.position.y, bob, dt * 10.0)
    _glb_root.rotation.z = lerpf(_glb_root.rotation.z, roll, dt * 10.0)
    _glb_root.scale = Vector3(1.0, 1.0 + sin(_walk_phase * 2.0) * 0.012, 1.0)
```

"弹一下 + 摆一下 + 一点纵向挤压"，在 Q 版角色上勉强能读成"走"。
但**这就是凑合**——能绑骨就别用这个。
