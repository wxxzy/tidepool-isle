# 03 · UI 视觉系统与主题换肤

> 目标：一套设计 token + 一次广播，让整个界面跟着昼夜换色，并且不依赖任何字体图标。
> 预计 30 分钟 · 前置：第 01、02 篇

---

## 先解决一个"看起来能用其实不能用"的问题

第一版 UI 我用了 emoji 当图标（☀ 🐟 ⭐）。在编辑器里正常，导出后**全是豆腐块**——
因为 GL Compatibility + Web 导出打包的默认字体不含这些字形。

顺带发现的第二个问题：我把 `theme.tres` 里写死了颜色，结果昼夜切换时界面纹丝不动。

所以这一篇要做两件事：

1. **图标自己画**（`ui_icon.gd`），不依赖字体
2. **颜色走 token + 广播**，不硬编码

---

## 步骤 1：设计 token 三件套

`palette.gd` 是个纯 `RefCounted`，只有常量和静态函数：

```gdscript
class_name Palette
extends RefCounted

const PHASES := ["dawn", "morning", "noon", "golden", "dusk", "night"]

# 尺寸 token
const RADIUS := 12
const BORDER_WIDTH := 2
const PAD_X := 14
const PAD_Y := 7
const FONT_XS := 11
const FONT_SM := 12
const FONT_MD := 15
const FONT_LG := 20
const FONT_XL := 30
```

颜色按**语义**命名，不按外观命名：

```gdscript
const SCHEMES := {
    "day": {
        "panel": Color(0.078, 0.345, 0.416, 0.86),   # #14586A
        "panel_alt": Color(0.118, 0.498, 0.549, 0.90),
        "accent": Color(0.941, 0.863, 0.706),        # 沙金
        "text": Color(1, 1, 1, 0.96),
        "text_muted": Color(0.749, 0.847, 0.863, 0.85),
        "border": Color(0.941, 0.863, 0.706, 0.35),
        "highlight": Color(0.910, 0.514, 0.239),     # 咬钩橙
        "safe": Color(0.373, 0.749, 0.561),
        "warn": Color(0.949, 0.757, 0.306),
        "danger": Color(0.910, 0.357, 0.239),
    },
    "golden": { ... },
    "night":  { ... },
}
```

**为什么用语义名？** 因为"day 的 accent 是沙金、night 的 accent 是暖灯光"——
如果叫 `sand_gold`，夜里就没法用了。语义名才能让同一套控件跨时段复用。

## 步骤 2：一次广播，全员换色

`theme_manager.gd`（autoload）：

```gdscript
signal theme_changed(phase: String, colors: Dictionary)

var _phase := "noon"

func set_phase(phase: String) -> void:
    if _phase == phase:
        return
    _phase = phase
    theme_changed.emit(_phase, palette())

func color(semantic: String) -> Color:
    return palette().get(semantic, Color.MAGENTA)   # 缺 token 用洋红，一眼看出来
```

**缺 token 返回洋红**这个细节很关键。用灰色兜底的话，你会很久都发现不了自己拼错了 key。

`main.gd` 在昼夜回调里只做一件事：

```gdscript
day_night.on_phase_changed = func(label: String, clock: String) -> void:
    var phase_name := str(GameData.daycycle.phase_at(day_night.hour).get("name", "noon"))
    ThemeManager.set_phase(phase_name)     # 先改色板，UI 自己刷新
    hud.set_time(label, clock, phase_name)
```

## 步骤 3：控件登记 + 统一重绘

难点不是"改颜色"，是**改哪些控件**。我在 HUD 里维护三张表：

```gdscript
var _panels: Array[Panel] = []      # 需要重刷 StyleBox 的面板
var _labels: Array[Dictionary] = [] # [Label, 语义色名]
var _bar_fills: Array[Dictionary] = [] # [ProgressBar, 语义色名]
```

建控件时登记，换肤时遍历：

```gdscript
func _apply_theme() -> void:
    for p in _panels:
        if is_instance_valid(p):
            p.add_theme_stylebox_override("panel", _panel_style())
    for it in _labels:
        var l: Label = it["node"]
        if is_instance_valid(l):
            l.add_theme_color_override("font_color", ThemeManager.color(it["color"]))
    for it in _bar_fills:
        ...
```

然后在 `_ready()` 里订阅：

```gdscript
ThemeManager.theme_changed.connect(func(_p, _c): _apply_theme())
```

### 坑：别忘了第一次

订阅只会在**下一次**换色时触发。第一次进游戏没有"变化"，所以 `_ready()` 末尾要手动调一次 `_apply_theme()`。

## 步骤 4：面板不是色块，是卡片

一开始我所有面板都是同一个扁平的 `StyleBoxFlat`，远看一片青，分不清层次。
改成"半透明底 + 描边 + 投影"三层后，层级立刻出来了：

```gdscript
func _panel_style(alpha := 1.0, radius := 12, shadow := true) -> StyleBoxFlat:
    var sb := StyleBoxFlat.new()
    var c: Color = ThemeManager.color("panel")
    c.a *= alpha
    sb.bg_color = c
    sb.set_corner_radius_all(radius)
    sb.set_border_width_all(Palette.BORDER_WIDTH)
    sb.border_color = ThemeManager.color("border")
    sb.set_content_margin_all(8)
    if shadow:
        sb.shadow_color = Color(0, 0, 0, 0.22)
        sb.shadow_size = 6
        sb.shadow_offset = Vector2(0, 3)
    return sb
```

`shadow_size = 6` + `offset (0,3)` 是试出来的：太小看不出，太大糊成一团。

## 步骤 5：自绘图标

`ui_icon.gd` 继承 `Control`，在 `_draw()` 里用 `draw_circle` / `draw_polygon` / `draw_arc` 画：

```gdscript
class_name IconGlyph
extends Control

enum Kind { SUN, MOON, FISH, REEL, STAR }

@export var kind: Kind = Kind.SUN
@export var tint: Color = Color.WHITE

func _draw() -> void:
    var c := size * 0.5
    var r := minf(size.x, size.y) * 0.5 - 1.0
    match kind:
        Kind.SUN:
            draw_circle(c, r * 0.52, tint)
            for i in 8:
                var a := TAU * i / 8.0
                var d := Vector2(cos(a), sin(a))
                draw_line(c + d * r * 0.66, c + d * r, tint, 1.6, true)
        Kind.MOON:
            draw_circle(c, r * 0.72, tint)
            draw_circle(c + Vector2(r * 0.42, -r * 0.28), r * 0.72, Color(0, 0, 0, 0))
        ...
```

月牙用"画圆 + 叠一个透明圆"是行不通的（透明不会擦除）。真正的做法是**用背景色再画一个圆盖住**，
或者用 `draw_polygon` 描出月牙轮廓。这里用的是后者更稳，源码里能看到具体路径。

**代价**：图标不能像字体那样一个字就换。好处：任何分辨率、任何平台都不会变成豆腐块。

## 步骤 6：进度条也别用默认的

Godot 默认 `ProgressBar` 是方角纯色。改成圆角 + 渐变：

```gdscript
func _ready() -> void:
    var bg := StyleBoxFlat.new()
    bg.bg_color = Color(0, 0, 0, 0.28)
    bg.set_corner_radius_all(5)
    add_theme_stylebox_override("background", bg)

    var fill := StyleBoxFlat.new()
    fill.bg_color = _fill_color
    fill.set_corner_radius_all(5)
    add_theme_stylebox_override("fill", fill)
```

张力条的颜色不是固定的，是按值插值：

```gdscript
var t := value / 100.0
var c := ThemeManager.color("safe").lerp(ThemeManager.color("danger"), smoothstep(0.55, 0.95, t))
```

`smoothstep(0.55, 0.95, t)` 让它在 55% 之前几乎不变色，快满时才迅速转红——
这比线性插值更符合"我什么时候该松手"的直觉。

## 步骤 7：提示文案要分情境

同一个"轻点提示"，不同时段该说不同的话。`data/goals.json` 里存了 6 个时段各一句：

```json
{
  "hints": {
    "dawn":  "水面很静，鱼在近岸觅食……",
    "noon":  "太阳高了，鱼都往深处躲……",
    "golden":"黄金时刻，大鱼开始活动。",
    "night": "夜钓靠手感，别急。"
  }
}
```

HUD 只负责取：

```gdscript
func set_situational_hint(phase: String) -> void:
    var h: Dictionary = GameData.goal_hints
    _hint_label.text = str(h.get(phase, ""))
```

文案外置之后，改一句话不用碰代码，也不用重新导出。
